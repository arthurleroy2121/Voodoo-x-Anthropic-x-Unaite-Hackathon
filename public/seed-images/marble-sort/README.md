# Marble Sort — Seed Images

10 reference frames used as the start image for the Scenario image-to-video
generation in step 4 (Creative Output).

## Current state

This folder is currently populated with **SVG placeholders** generated by
[`scripts/generate-seed-placeholders.mjs`](../../../scripts/generate-seed-placeholders.mjs).
They look stylized but are not real game screenshots.

## File convention

| Property | Value |
|----------|-------|
| Format   | SVG (current) or JPEG (recommended for real screenshots) |
| Aspect   | 9:16 vertical |
| Size     | 1080 × 1920 px (recommended for raster) |
| Naming   | `seed-01.<ext>`, `seed-02.<ext>`, …, `seed-10.<ext>` |

## Replacing placeholders with real screenshots

1. Drop `seed-01.jpg` … `seed-10.jpg` (10 files) in this folder, overwriting
   the SVG placeholders.
2. Bump the `EXTENSION` constant in
   [`data/seedImages.ts`](../../../data/seedImages.ts) from `'svg'` to `'jpg'`.
3. Refresh the dev server — the picker will pick up the new files automatically.

> ⚠️ Scenario's image-to-video models reject SVG inputs. The SVG placeholders
> are for the picker UI only; you must replace at least one with a real raster
> screenshot before kicking off a Scenario generation.

## Source of truth

The manifest at [`data/seedImages.ts`](../../../data/seedImages.ts) lists all 10
slots regardless of whether the files are physically present. Any missing file
will render as a grey placeholder in the picker — the app does **not** scan the
filesystem at runtime.
